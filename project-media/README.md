# PayloadStash brand assets

The production artwork uses one semantic story across every proportion:

1. YAML supplies the workflow.
2. Secret injection happens before transport.
3. HTTP and AMQP carry the payload.
4. PayloadStash captures and verifies the result.
5. Reports and logs redact loaded secret values.
6. Container and offline readiness remain global deployment capabilities rather than output artifacts.

## Banner family

| Asset | Size | Intended use |
| --- | ---: | --- |
| `PayloadStash-Banner.png` | 1536 x 682 | GitHub README and desktop documentation hero |
| `PayloadStash-Banner-OpenGraph.png` | 1280 x 640 | Open Graph and GitHub Pages link previews |
| `PayloadStash-Banner-Social.png` | 1200 x 628 | General social cards and embeds |
| `PayloadStash-Banner-16x9.png` | 1600 x 900 | Presentations, videos, and release announcements |
| `PayloadStash-Banner-Square.png` | 1080 x 1080 | Project directories, marketplaces, and square posts |
| `PayloadStash-Banner-Portrait.png` | 1080 x 1350 | Portrait social posts and feature announcements |
| `PayloadStash-Banner-Ultrawide.png` | 1584 x 396 | Ultra-wide profile and project covers |

The square and portrait compositions stack the workflow instead of cropping the wide design. The ultra-wide composition simplifies the workflow into one horizontal line while preserving the feature hierarchy.
